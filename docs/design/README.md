# Дизайн Академии Абрикософф

Исходный пакет дизайнера хранится в каталоге
[`handoff`](./handoff/Передача%20разработчику.dc.html).

Он используется как визуальная спецификация интерфейса:

- `Айдентика.dc.html` — знак, палитра и типографика;
- `Основа интерфейса.dc.html` — токены, компоненты и адаптивные правила;
- `Экраны - Публичные.dc.html` — каталог, вход и платёжный путь;
- `Экраны - Кабинет.dc.html` — кабинет, профиль и подписка;
- `Прототип - Новый ученик.dc.html` — кликабельные пользовательские сценарии;
- `assets/` — исходные SVG-логотипы и знаки.

HTML-файлы не являются производственным кодом. При реализации сохраняются
внешний вид и поведение макетов, а интерактивные элементы собираются
семантически корректно в приложении Next.js.

Дополнительные продуктовые спецификации:

- [карточка ученика v2](admin-student-card-v2.md) — компактная
  информационная архитектура read-only карточки Administration, её
  адаптивные состояния и критерии приёмки.

Внутренние ссылки в переданном файле `Передача разработчику.dc.html`
нормализованы под фактические имена файлов с обычным дефисом.
